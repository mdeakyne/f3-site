# Big Swings

*Workout idea — Ad Astra, Thursday 2026-07-30. Draft in Big Toe backblast format.*

**Concept:** A rotating station circuit. One 40 / 25 / 15 lb kettlebell (one of each),
so the three bell stations each hold exactly one man. The whole line rotates one
station per interval on the Q's call — everyone hits all three bells once per lap,
nobody waits, nobody fights over the heavy bell. Same rotating DNA as
*The Grinder (Remix)*.

**Gear:** 1 each of ~40 / 25 / 15 lb KB. Cinder block optional as an extra station
if the count is high.

---

## The stations (rotate one → per interval)

1. SSH
2. Merkins
3. Dips
4. **Big bell** — swings
5. **Mid bell** — swings
6. **Little bell** — swings
7. Movement (bear crawl out-and-back — rotate the movement each lap)

Rotating in order means you hit **big → mid → little back-to-back** every lap — a
heavy-to-light drop set — then the movement to travel it off, then bodyweight, and
around again. The heavy bell self-scales: fewer reps up top, more on the little bell.

**Movement rotates each lap:** bear crawl → crawl bear → walking lunges →
lunge walk → broad-jump burpees.

---

## How to cycle fairly

The single bells make **timed rotation the fair mechanism** — everyone works the
same clock and moves together, so there's never a line at a bell.

- **Seed the line:** one man starts on Movement, one on Big bell, the rest fill in
  the remaining stations.
- **Work the interval** (~45s). Q calls **"Rotate!"** — everyone steps to the next
  station, same direction.
- One lap = 7 intervals ≈ 5–6 min. Run **4–5 laps** to time.
- **Match stations to the count** so there's exactly one man per bell:
  - **7 PAX:** every station filled — perfect.
  - **Fewer than 7:** some stations sit empty each interval; that breather rotates
    to everyone equally. Still fair.
  - **More than 7:** *add bodyweight stations* (OP, Curls, Squats, Flutter Kicks) so
    stations ≥ PAX. Keep only **3 bell stations** — extras always land on bodyweight,
    never a second bell. Drop in the block as an 8th "swing" station if you've got it.
- **Cover the 6:** rotate on the Q's call, not on the fastest man — the clock keeps
  everyone together.

## Lead notes

- **Timed, not rep-based** — rep targets bottleneck at the single bells; the clock
  keeps the line moving as one.
- Bring a watch/phone timer; ~45s work is a good default, dial to the group's gas.
- If a man's toast on the big bell, he can rack it and do air squats till rotate —
  the interval ends the same for everyone.
- Rotating the movement each lap keeps the travel station fresh.
